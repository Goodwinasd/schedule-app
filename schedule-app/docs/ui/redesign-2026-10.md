# Академический редизайн · октябрь 2026

## Концепция

«Академический указатель»: интерфейс как печатный справочник расписания —
тёплая бумага, тёмно-зелёные чернила, антиква в заголовках, тонкие линейки
вместо крупных теней. Плотная таблица остаётся главным рабочим инструментом,
а главная страница читается как указатель: курс → группа, преподаватель,
аудитория.

Направление выбрано для техникума/колледжа: строго, спокойно, без
«стартап-градиентов», но современно — с понятной иерархией, крупными
кликабельными зонами и аккуратной тёмной темой.

для поднятых слоёв (модалки, выпадающие меню).

## Что переработано

- **Шапка**: монограмма, название, подпись «Колледж · учебный процесс»,
  компактные действия с линейными SVG-иконками. На телефоне подписи
  скрываются, остаются иконки.
- **Главная**: обложка-указатель с поиском по группам/преподавателям/
  аудиториям, сводкой и учебным годом; разделы с количеством записей;
  карточки с моно-аватаром (курс/инициалы/иконка аудитории), специальностью
  и стрелкой перехода.
- **Расписание**: недельная карусель в виде компактных чипов, панель действий
  в одну строку, таблица с липкой шапкой и колонкой времени, подсветкой
  текущего дня и субботы, аккуратными карточками пар, «+» на addable-ячейках.
  Даты-исключения вынесены в предупреждающую строку и больше не используют
  инлайн-стили.
- **Админка**: шапка с действиями, вкладки-подчёркивания, справочники в виде
  карточек с рамками, компактные строки и теги, таблица специальностей.
- **Свободные окна**: сегмент-контрол преподаватели/аудитории, вкладки дней,
  таблица с рамкой, карточки аналитики и графики в едином стиле.
- **Модалки**: бумажная поверхность, антиквенные заголовки, подписи полей
  капителью, единые кнопки; форма пары расширена до 720 px.
- **Тёмная тема**: переопределены те же токены, контраст текста и акцента
  проверен по значениям (акцент для текста — светлее фона).

## Файлы

- `static/css/style.css` — слой редизайна в конце файла (только `@media screen`,
  печать не затронута).
- `templates/index.html` — шапка, обложка главной, счётчики, версии ассетов.
- `static/js/modules/ui.js` — карточки, поиск, счётчики, дата/учебный год.
- `static/js/modules/schedule.js` — классы текущего дня, субботы и исключений
  без инлайн-стилей.
- `static/js/modules/main.js` — подпись кнопки темы без потери иконки.

## Проверка

Слой собран статически. Автоматические проверки (`pytest`, `node --check`,
скриншоты Playwright) в этой сессии не запускались: PowerShell в окружении
падает до выполнения команд с кодом `3221225794`. Перед коммитом нужно
прогнать:

```bat
python -m pytest tests/ -q --ignore=tests/e2e --tb=short
python -m pytest tests/e2e -q
node --check static/js/modules/ui.js
node --check static/js/modules/schedule.js
node --check static/js/modules/main.js
```

и снять скриншоты главной, таблицы, админки и мобильной версии.
