# Аудит кнопок · октябрь 2026

Единая кнопочная система для академического редизайна: Primary / Secondary /
Danger / Icon. Все размеры, цвета и радиусы — из токенов `:root`; литеральные
цвета в компонентах не добавлялись.

## Роли и размеры

| Роль | Высота | Вид | Где применяется |
|---|---|---|---|
| **Primary** | 44 px (`--btn-h-lg`) | заливка `--accent-500`, текст `--accent-on`, вес 700 | вход, сохранение, генерация, добавление недели, подтверждение |
| **Secondary** | 40 px (`--btn-h`) | прозрачный фон, рамка `--color-border`, текст secondary | отмена, закрыть, назад, управление неделей, экспорт |
| **Danger** | 40 px | `--danger` / `--danger-hover` | удалить неделю, удалить пару, очистить корзину |
| **Compact primary** | 32 px (`--btn-h-sm`) | та же заливка, но для плотных строк | «Добавить» в справочниках, настройках, учебном плане |
| **Icon** | 36×36 px (`--btn-icon`) | квадрат, иконка по центру | тема, настройки, вход/выход, стрелки недель |
| **Compact icon** | 28×28 px (`--btn-h-xs`) | мягкий красный фон, красный крест | удаление строки в справочнике / таблице |

Кнопки сбрасывают скачки высоты: `.btn-sm` — 32 px, `.btn-xs` — 28 px,
`.btn-lg` — 48 px. В одной панели используются кнопки одной высоты.

## Раскладка

- **Широкие модалки**: secondary слева, primary справа (`margin-left: auto`),
  danger — отдельно слева.
- **Узкие модалки** (`modal-narrow`: вход, подтверждение, kimi, custom confirm):
  колонка `primary` сверху на всю ширину, secondary под ней.
- **Мобильные (≤768 px)**: все `.modal-actions` — колонка `column-reverse`:
  primary сверху на всю ширину, secondary ниже, danger внизу; spacer скрыт.
- **Формы**: input/button в `.field-row` имеют одну высоту (38 px в настройках
  и импорте, 32 px в плотных справочниках).
- **Иконки**: header на мобильном 36×36, carousel arrows 36×36, row actions
  28×28, form quick-add 38×38.
- **Публикация**: segmented control с равными кнопками, активное состояние
  заливкой accent-soft / warning-soft, без неоновых цветов.

## Что изменено в коде

- `static/css/style.css` — добавлен финальный блок «Единая кнопочная система»
  с токенами `--btn-*` и переопределениями ролей/размеров.
- `templates/index.html` — `modal-narrow` для входа/подтверждения, icon-кнопки
  быстрого добавления, порядок кнопок в генерации, aria-label для иконочных
  действий, dropdown-акценты.
- `schedule.js` — сегментированный статус публикации и классы `is-active`.
- `references.js`, `settings.js`, `curriculum.js`, `trash.js` — роли кнопок,
  compact danger icon, outline accent.
- `modal.js`, `utils.js` — kimi/custom confirm переведены на общие классы
  `.modal-content`, `.modal-actions`, `.modal-narrow`, без инлайн-стилей.
- `ui.js` — «Повторить запрос» стал primary.
